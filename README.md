# Resume Analyzer

An AI-powered Resume Analyzer built with Python, Groq LLM, and Pydantic.

## Features

- Extracts resume information from PDF
- Uses Groq LLM for structured data extraction
- Validates output with Pydantic
- Compares skills with job requirements
- Calculates a Good Fit Score

## Tech Stack

- Python
- Groq API
- Pydantic
- dotenv
